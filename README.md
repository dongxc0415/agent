# 特工 - 基于LangChain的具有长期记忆的Agent助手

## 项目简介
普通的AI聊天机器人每次重启后就会"失忆"，无法记住用户的习惯和历史对话。

这个项目构建了一个具有长期记忆的智能助手——能记住你的个人偏好，查阅PDF文档，回答天气、计算等实时问题，重启之后依然记得你是谁。

经过测试验证：用户偏好和历史对话在程序重启后均可成功召回。

## 功能
- 长期记忆：跨会话记住用户偏好
- 短期记忆：保留最近5轮对话上下文
- PDF知识库：上传文档后可提问
- 实时工具：天气查询、数学计算、日期获取

## 技术栈
- LangChain Agent + Tool Calling
- Chroma 向量数据库
- DashScope (通义千问)
- Gradio 前端
